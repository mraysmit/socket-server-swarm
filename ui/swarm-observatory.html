Swarm Observatory

Swarms

Start a swarm

Starts real socket servers inside this program, from 1 to 100, each on ports the operating system picks. The name must begin with a letter. When the harness was started with gossip, the servers find each other through the first one.

Selected swarm

Chooses which swarm the actions in this box apply to. It follows the server you select. Stop closes every server in the chosen swarm. Stop all closes every swarm.

Add servers

Starts more servers in the chosen swarm. They are numbered after the highest number it has had, and with gossip they join through the swarm’s first server. A swarm holds at most 100 servers.

Send to every server

Sends one message to each server in the chosen swarm and reports how many answered OK. Plain text is sent as an echo; a JSON request is sent as it is. To talk to one server and see its raw reply, use the Command tab.

Load test

Checks that every server answers correctly under load. Sends the requests you set, as echo messages spread evenly across the chosen swarm, with up to that many clients asking at once. Each reply is checked against what was sent. Shows how many were correct, the time taken and the requests per second. It changes nothing in the swarm.

Demo timings: round 1 s, suspect after 7 s, dead after 16 s. Real values are set in the gossip config.
